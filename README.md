Инструкция по запуску
1. Создайте базу данных orteka в MySQL.
2. Импортируйте структуру базы данных.
3. Отредактируйте файл конфигурации подключения к базе данных db.php, указав правильные параметры.
4. Настройте веб-сервер (Apache) на корневую директорию проекта (domains).
5. Убедитесь, что PHP включен и правильно настроен на веб-сервере.
6. Откройте веб-6раузер и перейдите по URL вашего сайта (http://localhost/orteka).
